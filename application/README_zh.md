# 大语言模型智能体“知国家、不知农户”：数据与代码包

本目录为2026年11月7日修订版（对应稿件第4版），整合原完整仓库、10月17日更正和10月19日核对更新。图6与图1–8及附图S1一起放在figures目录下，各图均包含绘图代码或源文件、数据、输出和正文参考图。

覆盖图1–8、附图S1、表1–3和附表S1–S12。内容包括490个固定农户/地块档案、模型预测和原始响应、提示词及运行清单、全国与个体分析、抽样权重、完整调查性状模型的去标识输入，以及全部图的代码、源数据和图件。

## 运行

建议Python 3.12：

```bash
python -m pip install -r requirements.txt
python scripts/validate_release.py
python run_all.py --bootstrap 200
```

200次用于检查流程与点估计，论文主要区间需要10000次：

```bash
python run_all.py --bootstrap 10000
```

性状回归按自己的规则使用调查500次、预测2000次。分析结果写入`reproduced/`，归档结果不被替换。只重绘全部图可运行：

```bash
python figures/run_all.py
```

## 查找文件

- `data/`：农户档案、去标识完整调查输入、模型响应、统计结果和当前所有表格。
- `src/`：实验、抽样、统计分析和源数据准备代码。
- `figures/`：图1–8及附图S1，各图采用同样的目录习惯，附源数据、代码/源文件与输出。
- `scripts/`：统一重跑、官方数据获取、完整性和结果校验工具。
- `prompts/`与`config/`：提示词模板、随机化清单、提示哈希和调用记录。
- `docs/`：详细运行方法、文件与结果对应表、数据来源和仍无法精确复现的范围。

原始LSMS-ISA调查文件约960MB，不重复塞进Git仓库。本包包含可重跑相关模型的紧凑去标识数据，并提供官方固定版本下载信息和校验值。官方数据来自 https://doi.org/10.5281/zenodo.15774761 ，许可为CC0 1.0，并保留来源引用。

## 需要区分的两点

图1当前稿的源是作者提供的最终图片；只找到旧版可编辑PPT，已标为历史版本。图2的全国回归点可按已报告数值重绘，但全国统计基准的完整精度年度输入、跨年度调查年份映射及原始区间实现仍未找到。本包明确记录这些限制，不把舍入输入核算标成原始分析的精确重现。

当前版本为0.2.1（2026-10-20）。论文作者名单中的同名重复项、模型生成数据的许可和未来GitHub/Zenodo公开标识仍需在真正发布前确定；未替作者生成不存在的仓库链接或DOI。整理本地文件并不等于已上传GitHub。
