# Figure 1: supplied study-design raster

`source/Fig1_supplied.png` is the image embedded in the accepted October 17
figure document, preserved byte for byte (2,464 × 1,820 pixels). The same asset
is retained in `reference/accepted_manuscript.png` and `outputs/Fig1.png`.
It is an author-supplied conceptual diagram, not a plot derived from a numeric
figure table. No current editable vector source was found in the supplied files.

`export_fig1.py` copies the current raster and optionally places it in a raster
PDF. This preserves the supplied contents; it does not make an editable vector
figure or increase the source resolution. The exact manuscript caption is in
`reference/caption.txt`.
