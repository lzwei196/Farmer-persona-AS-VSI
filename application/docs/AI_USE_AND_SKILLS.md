# AI use and public workflows

Two distinct uses of AI should not be conflated.

1. **Objects of study:** Claude, Codex, and Kimi command-line clients generated the archived
   farmer-agent decisions under controlled prompt manipulations.
2. **Research assistance:** AI tools assisted with code organization, language editing, figure
   iteration, and preparation of this reproducibility package. Authors remain responsible for
   claims, statistics, citations, code, and the submitted manuscript.

This disclosure should be aligned with the target journal's current AI policy before submission.
