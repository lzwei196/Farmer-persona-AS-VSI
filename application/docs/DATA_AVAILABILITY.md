# Data and code availability

This local package contains the fixed pseudonymized study profiles, consolidated predictions, synthetic model responses, prompt-design comparisons, compact survey-analysis input, analysis results and figure source data. All main and supplementary figure and table source files are mapped in the repository documentation. Canonical inputs and reported-value display snapshots are labeled separately.

The reused LSMS-ISA harmonised dataset v2.0 is openly available under CC0 1.0 from https://doi.org/10.5281/zenodo.15774761 and described by Bentze and Wollburg (2025), https://doi.org/10.1038/s41597-025-05639-9. Its large `.dta` files are obtained with the supplied official-source acquisition route. Source attribution and transformation notes accompany the compact survey view.

The package is a local release candidate. No public GitHub repository URL or DOI for this study's release has been supplied, and none is invented. After publication destinations exist, cite those exact identifiers in the manuscript. Model-generated rationales are computational outputs and do not represent interviews with farmers. Licence choices for study-generated data are distinguished in DATA_LICENSE.md.

The complete source inputs and original bootstrap implementation of the national-statistics benchmark were not located; its archived estimates and precision-limited reconstruction are identified separately. The supplied current Figure 1 image is retained, but its current editable engineering file was not located. These limitations are recorded rather than described as fully reproduced.
