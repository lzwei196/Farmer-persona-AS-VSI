## Method and cautions

- Primary bootstrap: 10,000 paired resamples within each country's observed adoption strata; seed 20260826.
- Cluster sensitivity: 5,000 household resamples.
- The four-country sample was deliberately balanced on adoption and is not weighted to national adoption prevalence. These metrics characterize this experimental sample.
- The agent summary treats the 12 completed model×tier configurations as fixed and quantifies sampling uncertainty over plots; it does not treat model choice as a random effect.
- Conditional-intensity comparison uses a common observed-positive subset. An LLM zero rate remains zero there, so its intensity metric includes false-negative adoption; this is transparent but cannot be a pure latent E[N | adopt] estimate because the LLM did not return one.
- Across country×cell combinations, disagreement between the LLM's explicit adoption answer and whether its numeric rate was positive ranged from 0.0% to 0.0%.
- Nigeria's hurdle intensity model extrapolates badly in absolute-error terms; use the constrained RF for Nigeria's overall-r comparison, as v2 did.
