# Data licensing and attribution

The MIT licence applies to original code and does not automatically license every data file.

## Reused survey data

The official LSMS-ISA harmonised dataset v2.0 is an open CC0 1.0 deposit at https://doi.org/10.5281/zenodo.15774761. The package retains citation to Bentze and Wollburg (2025), https://doi.org/10.1038/s41597-025-05639-9. Compact pseudonymized survey-analysis views are transformations of that source: fields are selected, quality-control and eligibility rules applied, and sampling-group labels replaced. They are not newly collected observations. Source attribution, CC0 information and transformation notes are retained to make provenance clear.

The large original third-party `.dta` files are downloaded from the official versioned archive rather than duplicated in Git. See the acquisition metadata and scripts for checksums and file sizes. The repository does not impose a new access restriction on this open source.

## Model-generated and study-generated data

Model responses, study-specific arrangements of model data and new figure/analysis outputs are distinct from the source survey. The authors' choice of a public licence for those study-generated materials has not been recorded; this file does not grant that licence on their behalf. A local release candidate may retain them for review and preparation. A publication release should state the authors' chosen licence explicitly.

The vendored humanizer material retains its original MIT notice. Historical author-provided figure assets retain their provenance. No licence here overrides a third-party asset's own terms.
